# Карточки: английский и словацкий

Приложение для изучения слов с интервальным повторением. Работает целиком в браузере, без сервера и без ИИ. Данные хранятся на твоём устройстве.

## Как выложить на GitHub Pages

1. Зайди на github.com, войди в аккаунт (или создай его).
2. Нажми «+» вверху справа → «New repository». Назови, например, `cards`. Выбери «Public» и нажми «Create repository».
3. На странице репозитория нажми «uploading an existing file» (или «Add file» → «Upload files»).
4. Перетащи (или выбери) файлы: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-180.png`, `icon-192.png`, `icon-512.png`. Сам `README.md` загружать не обязательно. Нажми «Commit changes».
5. Открой «Settings» → «Pages». В разделе «Build and deployment» выбери Source: «Deploy from a branch», Branch: `main`, папка `/ (root)`, нажми «Save».
6. Подожди 1–2 минуты и обнови страницу. Появится адрес вида `https://ТВОЁ-ИМЯ.github.io/cards/`.

## Как поставить на телефон

- **iPhone:** открой адрес в Safari → «Поделиться» → «На экран Домой».
- **Android:** открой адрес в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

## Важно знать

- Прогресс хранится в браузере на каждом устройстве отдельно и не синхронизируется. На телефоне и на компьютере будут разные базы.
- Если обновишь `index.html` на GitHub, адрес и данные не изменятся. Если сменишь имя репозитория или аккаунта, адрес станет другим и данные не перенесутся сами.
- Чтобы перенести данные: во вкладке «Слова» нажми «Показать данные», скопируй текст, а на новом адресе вставь его в «Резервная копия» и нажми «Восстановить». Фото в такую копию не входят.
- После обновления файла может понадобиться обновить страницу дважды, чтобы подтянулась новая версия.
- Слова добавляются во вкладке «Добавить»: по одному или списком в блоке «Импорт из заметок» (формат `слово (произношение) - перевод пример`).
